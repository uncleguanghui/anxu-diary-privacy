安叙日记 · 隐私政策

更新日期：2026-11-08

安叙日记（以下简称「本应用」）是一款纯本地日记与 AI 情绪陪伴工具。我们（开发者）深知个人日记与情绪记录的私密性，因此把「数据只属于你」作为产品的第一原则。

1. 数据存储

  • 你的全部数据——日记、标签、定位记录、聊天会话、AI 记忆、照片——仅存储在你的设备本地（应用沙盒 + iOS 钥匙串）。
  • 本应用没有任何自有服务器，不会主动向任何服务器上传你的数据，也没有账号系统、没有云同步。
  • 卸载应用即删除全部本地数据。

2. 你主动配置第三方服务后的必要传输

应用的 AI 聊天功能需要你自行注册并配置第三方大模型服务商的 API Key（默认推荐 DeepSeek）：

  • 配置后，你在聊天中输入的文字、图片，以及为了让 AI 更懂你而注入的必要上下文（记忆摘要、相关日记片段），会经由你的设备直接发送给你配置的服务商处理。
  • 该传输由你的 API Key 授权、完全由你控制：可以随时在「设置 → AI 服务设置」更换服务商或关闭云端开关。
  • 开发者无法接触这些内容：我们不代理、不缓存、不存储任何聊天数据。API Key 只保存在你设备本地的 iOS 钥匙串中。
  • 若你未配置 API Key，AI 聊天功能不会发起任何网络请求；写日记等全部其他功能离线可用。

3. 天气功能

  • 在你授权定位权限后，应用每天最多一次使用你的粗略位置向公开天气服务（Open-Meteo）请求当日天气，结果缓存于本地。该请求不包含任何可识别你个人身份的信息。
  • 你可以拒绝定位权限，或随时在系统设置中关闭；拒绝不影响其他功能。

4. 权限使用说明

| 权限 | 用途 | 可否拒绝 |

|---|---|---|

| 相册 | 选择照片插入日记、设置头像/背景、AI 发图 | 可拒绝，不影响核心功能 |

| 相机 | 拍摄照片插入日记/聊天 | 可拒绝 |

| 定位 | 查询当天天气 | 可拒绝 |

| 通知 | 每日写日记提醒 | 可拒绝 |

5. 数据导出与删除

  • 「设置 → 数据导出」可一键导出全部数据（JSON + Markdown + 照片 + 记忆），文件完全由你保管、可用任何工具打开。
  • 「设置 → 数据清理」可分类彻底删除聊天/记忆/日记/日记本。

6. 未成年人

本应用面向一般用户，不专门收集未成年人信息；建议未成年人在监护人知情下使用 AI 聊天功能。

7. AI 能力边界（重要）

  • 本应用是情绪陪伴与记录工具，不是心理咨询或医疗软件。AI 不会给出心理诊断、病情判定或医疗建议。
  • 当你表达严重心理危机时，AI 会停止常规对话，提供人文陪伴并引导你联系专业援助（全国心理援助热线 12356；紧急情况 120/110）。

8. 联系我们

如对本政策或数据处理有任何疑问，请通过 App Store 页面提供的支持渠道联系开发者。
